# Specification approval

Use this fallback only when the exact ready SPEC was not already explicitly authorized during specification. Present the complete ready SPEC as the work item's human decision point. Do not create tasks or start implementation until the human approves this exact revision. Record approval with `npx --no-install flow approval record _flow/work-items/W###-name/spec.md`, then route again.

Any later scope, public-contract, or material architecture change requires a revised SPEC and new approval.
